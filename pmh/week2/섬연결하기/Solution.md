# 섬 연결하기

## 문제 분석
- n개의 섬을 모두 서로 이동할수 있도록 연결해야함
- costs[i] = [a, b, cost]
  - a섬과 b섬을 연결할 수 있다. 
  - 해당 다리를 건설하는 비용은 cost이다.
- 모든 섬이 연결 되어야함 그러나 모든 다리를 만들 필요는 없다
- 따라서 모든 정점을 연결하면서 다리 비용의 합이 최소가 되는 방법을 찾아야한다.
---
## 풀이 고민
### 자료구조/알고리즘 후보
- 다익스트라 알고리즘
- Prim알고리즘 + 우선순위 큐

### 선택지 A 설명
처음에는 경로의 최소 비용이라고 하니 다익스트라 알고리즘을 쓰면 어떨가 싶어 생각했다.  
다익스트라 알고리즘을 통해 모든 경로의 최소비용을 구하고 다 더하면 되지 않을까 싶었다.  
그러나 그렇게할시 다익스트라 알고리즘은 a -> b  최소 비용은 구할수있지만 모든 정점을 연결하면서 다리 비용의 합이 최소가 되는 방법을 구할수가없다.

### 선택지 B 설명
Prim 알고리즘은 하나의 섬에서 시작해서 혀재까지 섬과 연결할 수 있는 다리 중 비용이 가작 작은 다리를 계속 선택하는 방법  
먼저 입력으로 주어진 다리를 인접 리스트로 형태로 저장
```java
List<int[]>[] graph = new ArrayList[n];
```
그 이후 각 원소에는 {연결된 섬,다리 비용} 같은 정보를 저장하고 다리는 양방향이기 떄문에 양쪽 모두 저장한다.  
```java
graph[a].add(new int[]{b, price});
graph[b].add(new int[]{a, price});
```
그 다음 우선순위 큐를 사용해 현재 선택할 수있는 다리 중 비용 가 작은 다리를 찾는다
```java
PriorityQueue<int[]> pq =
    new PriorityQueue<>((a, b) -> a[1] - b[1]);
```
그 이후 0 번 섬 {0,0} 부터 시작한다.  
우선순위 큐에서 비용이 가장 저렴한 다리를 하나씩 꺼낸다.    
이미 방문한 섬일시 이미 최소비용 다리에 포함된 섬이므로 무시한다.    
아직 방문하지 않으 섬이라면 해당 다리를 선택후 연결한다.  
그후 새롭게 연결된 섬에서 갈 수 있는 다리들을 다시 우선순위 큐에 넣는다.  
이 과정을 반복시 현재 연결된 섬에서 갈수 있는 가장 저렴한 다리부터 선택하게 되고 결과적으로 모든 섬을 최소 비용으로 연결할 수 있다.

## 최종 결정 및 근거
## 최종 결정 및 근거

**Prim 알고리즘 + PriorityQueue**를 선택했다.

하나의 섬에서 시작하여 연결 가능한 다리를 우선순위 큐에 넣고, 그중 비용이 가장 작은 다리를 계속 선택하면 된다.

`visited` 배열을 사용하여 이미 연결된 섬을 다시 선택하지 않도록 하기 때문에 **사이클도 자연스럽게 방지할 수 있다.**

따라서 다음 과정을 반복한다.

```text
0번 섬에서 시작
      ↓
연결 가능한 다리를 PQ에 추가
      ↓
가장 저렴한 다리 선택
      ↓
새로운 섬 연결
      ↓
새롭게 연결된 섬의 다리를 PQ에 추가
      ↓
     반복
```
