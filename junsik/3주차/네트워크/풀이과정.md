## 문제 분석

- 컴퓨터 개수 `n`과 연결 행렬 `computers`가 주어짐.
- 서로 연결된 컴퓨터 묶음을 하나의 네트워크로 간주할 때, 전체 독립된 네트워크 개수 계산.
- 특정 컴퓨터에서 출발하여 연결된 모든 컴퓨터를 빠짐없이 탐색해야 하는 그래프 연결 요소(Connected Component) 판단 문제.

---

## 풀이 고민
### 자료구조/알고리즘 후보
- 선택지 A: DFS(깊이 우선 탐색) 활용한 연결 요소 탐색

### 선택지 A 설명
- 한 컴퓨터에서 시작해 연결된 다른 컴퓨터를 재귀적으로 끝까지 파고들며 방문 처리(`visited = true`)하는 방식.
- 메인 루프에서 아직 방문하지 않은 컴퓨터를 발견할 때만 새 네트워크의 시작으로 판별하여 카운트를 증가시킴.

---

## 최종 결정 및 근거
**선택지 A 채택**
- 처음 구상한 그래프 탐색 아이디어를 DFS 재귀 함수 형태로 정확히 구현하여 예외 없이 해결함.
- 모든 노드와 간선을 1회씩 탐색하므로 $O(V + E)$의 최적화된 시간 복잡도로 통과 가능함.

---

## 회고
- 초기 중첩 루프 구조에서 재귀 호출 구조로 리팩토링하면서 DFS의 정석적인 형태를 확립함.
- 대괄호 연산자 오타 등의 실수를 교정하고 참조자(`&`)를 통해 대용량 벡터 전달 시 메모리 오버헤드를 방지함.
