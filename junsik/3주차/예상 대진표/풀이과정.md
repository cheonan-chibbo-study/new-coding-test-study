## 문제 분석

- N명이 참가하는 토너먼트에서 참가자 A와 B가 몇 번째 라운드에서 만나는지 계산.
- 라운드가 지날 때마다 승자들은 번호를 새로 부여받음 (1번-2번 승자는 1번, 3번-4번 승자는 2번).
- 대결 조건은 두 참가자가 같은 라운드 경기에서 매칭되는 시점, 즉 번호가 같아지는 순간임.

---

## 풀이 고민
### 자료구조/알고리즘 후보
- 선택지 A: 그리디 탐색
- 선택지 B: 수학적 시뮬레이션 (수식 기반 번호 갱신)

### 선택지 A 설명
- 매 순간의 최적의 선택을 찾아 나가는 탐욕법 접근. 
- 그러나 대진표 문제는 선택의 문제가 아닌 토너먼트 규칙에 따른 고정된 번호 변동이므로 그리디 알고리즘 적용 모델로 부적합함.

### 선택지 B 설명
- 라운드 이동 시 다음 번호가 `(현재 번호 + 1) / 2`로 줄어드는 토너먼트의 수학적 규칙 활용.
- `while` 문을 통해 `a`와 `b`가 같아질 때까지 두 번호를 동시에 축소하며 라운드 수(`answer`)를 카운트함.

---

## 최종 결정 및 근거
**선택지 B 채택**
- 선택지 A(그리디)의 한계를 인지하고 단순 수식 시뮬레이션인 선택지 B로 선회하여 해결함.
- 라운드가 지날 때마다 데이터 규모가 절반씩 줄어드는 특성상 $O(\log N)$의 매우 효율적인 시간 복잡도로 정답 도출 가능.

---

## 회고
- 복잡한 자료구조 없이 정수 나눗셈의 특성을 활용한 규칙성(`(x + 1) / 2`)만으로 토너먼트 매칭을 명확하게 구현함.
- `a != b` 조건을 통해 직관적이면서도 예외 없이 반복문을 탈출하도록 흐름을 제어함.
